CDC Badge Updater

TROPIC01 Firmware Updater & Factory Reset Tool

Checking latest version...

One-shot helper firmware for the TROPIC01-enhanced CDC Badge v1.0 / v1.1 (ESP32-S3). It does two jobs: update the TROPIC01 secure element firmware to the embedded version, or perform a clean factory reset (NVS + TROPIC01 user data) without writing new firmware. R-Config and pairing keys stay untouched, so the chip remains addressable. After it finishes, re-flash the normal CDC Badge OS.

What this firmware does

  1. Boots and shows STARTING on the e-paper.
  2. Checks battery / USB power. Refuses to start if too low.
  3. Erases NVS and all populated TROPIC01 ECC / R-Memory slots. Pairing keys (R-Config) are NOT touched.
  4. Reads current TROPIC01 firmware version and shows it next to the embedded version.
  5. Waits for Y (flash new firmware) or N (factory reset only) on the keypad.
  6. On Y: rewrites TROPIC01 RISC-V and SPECT firmware. DO NOT POWER OFF. Shows SUCCESS or FAILED.
  7. On N: skips firmware write and shows ABORTED. The wipe from step 3 has already happened, so the chip is in a clean state.
  8. Halts. Reflash the normal CDC Badge OS to resume use.
! The TROPIC01 firmware update (option Y) is not interruptible. Power loss or reset during step 6 can brick the secure element. Keep the badge on USB and the battery charged. The factory-reset-only path (option N) carries no such risk.

Enter Bootloader Mode

On the back of the badge, locate the FLASH and RESET buttons.

  1. Press and hold FLASH.
  2. While holding FLASH, press RESET once and release it.
  3. Release FLASH.
  4. After flashing, press RESET once to start the updater.

Connect the badge via USB, enter bootloader mode, then click the button below.

Requirements

  • Google Chrome or Microsoft Edge (version 89+)
  • USB cable (data-capable, not charge-only)
  • Badge in bootloader mode (see steps above)
  • Battery charged or USB connected during the TROPIC01 update
